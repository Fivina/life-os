## Intentional boundaries

- Semantic-memory Events are audit events but do not increment canonical `WorldRevision`; memory and episodes are contextual knowledge, not current canonical truth.
- Vector ranking is evaluated over a bounded per-user candidate set. A pgvector ANN index is intentionally deferred until corpus size justifies fixed-dimension index management.
- Curator and embedding failures degrade safely; they may delay memory creation but cannot block canonical application workflows.
- v1.3 and later planner/domain features remain explicitly out of scope.
