# Life OS v1.9B

## Boundaries

Quick Capture means that a real-world fact or requested state change should enter canonical Life OS state. Notebook means that a thought should be preserved without changing goals, plans, calendars, finances, or other domain truth. Self Core checks Notebook commands first and routes only recognized real-world statements into Quick Capture.

Quick Capture stores a versioned proposal. It never writes domain tables directly and never creates `PlanBlock`. An accepted proposal is revalidated and delegated to Learning, Finance, Kitchen, or Commitments. Consequential proposals require confirmation. Ambiguous targets, missing classification, and low-confidence interpretations enter the Review Queue.

## Review Queue

Review items preserve bounded original evidence, candidate values, ambiguity reasons, source references, and expected target versions. Active items are deduplicated by a stable fingerprint. Accept and edit-and-accept revalidate current state before calling the canonical service. Reject and dismiss leave canonical state unchanged. Expired and superseded items remain historical records and are not surfaced as pending work.

The queue supports quick captures, receipt lines, uncertain memory candidates, finance classification, canonical-correction placeholders, and existing uncertainty. It is not a recommendation inbox, Notebook, Attention list, or feedback queue.

## Intelligence Controls

The Settings surface persists one settings record per user. Memory and pattern visibility affect context construction. Skill disabling prevents Self Core from routing to that skill. The monthly budget is read by `AIUsageService`; custom thresholds use 80%, 90%, and 100% for warning, Economy-only routing, and optional suppression. Quiet mode suppresses non-urgent mentions, proposals, and questions in the host Attention policy but cannot bypass confirmations, errors, explicit results, or canonical write authority.

Provider state exposes enabled/configured/available status, capabilities, and model names without exposing credentials. Usage is read from the real AI audit ledger. Conversations can be inspected and archived; archival does not delete canonical domain facts. Memory correction and forgetting use the existing Memory service. Export uses the authenticated structured export and now includes v1.9B records.

## Realtime And Privacy

Quick Capture, Review Queue, and settings changes emit existing Events, increment WorldRevision, and flow through the existing realtime invalidation bus. Raw capture text is retained only in the capture audit record; it is not automatically promoted to semantic memory or training data. Cognitive traces store explicit interpretation, candidates, policy result, review reference, and final canonical reference, never hidden reasoning.
